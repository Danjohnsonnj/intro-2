How do actors differ from classes for shared mutable state?

Actors serialize access to their mutable state — only one task enters at a time. Key differences from classes:

  • Isolation — cross-actor access requires await
  • Reference semantics — like classes, but Sendable-checked
  • No data races — compiler enforces safe boundaries
actor Counter {
  private var value = 0
  func increment() { value += 1 }
}

Use actors when multiple async tasks touch the same state.
